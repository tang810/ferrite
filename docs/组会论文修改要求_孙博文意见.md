# 组会论文修改要求：孙博文意见整理

来源：用户粘贴的腾讯会议纪要文本。

## 一、论文主线需要升级

当前论文不能只写“多层铁氧体磁屏蔽”，需要明确写成：

```text
复合 / hybrid 磁屏蔽结构：
多层铁氧体薄带基体 + 外层非晶/纳米晶高磁导材料
```

师兄强调：

- 题目和 intro 里有 `composite / flexible magnetic shielding` 的概念，就必须解释“复合”体现在哪里。
- 复合磁屏蔽不是只讲铁氧体，而是讲铁氧体与高磁导软磁材料组合。
- 论文里要写非晶、纳米晶作为常用工程带材，尤其是后续实物里要用纳米晶。

建议论文表述：

```text
The proposed shield is a hybrid multilayer structure, in which flexible ferrite sheets form a low-conductivity base and an additional amorphous or nanocrystalline ribbon provides a high-permeability magnetic path.
```

中文逻辑：

```text
铁氧体负责低电导、低涡流噪声和柔性基体；
非晶/纳米晶负责提高磁导率和屏蔽系数；
两者组合形成低成本、可制备、可弯曲的复合磁屏蔽结构。
```

## 二、Introduction 必须新增的内容

### 1. 加入非晶和纳米晶背景

引言中要增加：

- 非晶带材是常用工程软磁材料。
- 纳米晶带材也是高磁导软磁材料，适合作为外层增强材料。
- 两者相比坡莫合金 / mu-metal 可能具有成本和工程制备优势。

建议写法：

```text
Amorphous and nanocrystalline ribbons are commercially available high-permeability soft-magnetic materials. Compared with conventional permalloy or mu-metal shells, ribbon-based amorphous or nanocrystalline layers can be more compatible with low-cost and flexible shield fabrication.
```

### 2. 说明为什么是复合结构

需要强调：

```text
单纯铁氧体 SF 偏低；
单纯金属高磁导材料可能带来磁噪声/涡流/成本问题；
因此采用铁氧体 + 非晶/纳米晶的复合方案。
```

建议写法：

```text
Ferrite materials are attractive for low-noise shielding because of their high resistivity, but the shielding factor of a thin ferrite cylinder can be limited. A hybrid ferrite-metallic soft-magnetic structure is therefore investigated to improve attenuation while retaining the low-noise motivation of the ferrite base.
```

### 3. 说明材料选择的工程原因

师兄明确提到：

- 坡莫合金贵、重。
- 纳米晶和铁氧体薄带可能成本更低。
- 还能保持柔性。

论文里可以放在 Introduction 末尾或 Discussion：

```text
The use of ferrite sheets and nanocrystalline ribbons is also motivated by engineering considerations, including material availability, cost, and compatibility with flexible or conformal shield assembly.
```

## 三、磁导率怎么写

组会结论：

- 当前仿真可以先用常量磁导率。
- 非晶/纳米晶磁导率后续要测。
- 仿真中的磁导率应解释为“初始磁导率”。
- 因为应用场景是地磁场/低频/无强激励条件，可以用初始磁导率作为近似。

### 当前仿真参数

会议中提到：

```text
非晶/纳米晶先用常量磁导率做仿真；
后续拿到厂家或实测磁导率后再更新仿真。
```

注意：之前项目中用过：

```text
amorphous: mu_r = 10000
nanocrystalline: mu_r = 50000
```

但会议里师兄说“非晶 5 万也是正常值”。因此论文中应避免把材料参数写得过死，建议写：

```text
The relative permeability values used in the present FEM model are initial-permeability assumptions for low-field operation. These values will be updated after material characterization.
```

### 论文中建议写法

```text
Since the shield is intended to operate under the geomagnetic field without a strong excitation field, the soft-magnetic ribbons are modeled using their initial relative permeability. The initial permeability can be obtained from the slope of the B-H curve around H = 0. In the present simulation stage, representative constant values are used for amorphous and nanocrystalline ribbons, and the model will be updated after material characterization.
```

中文逻辑：

```text
不是随便设常数；
这个常数代表低场初始磁导率；
初始磁导率来自 H=0 附近 B-H 曲线斜率；
地磁场下没有强激励，所以这样近似合理；
后续会用实测值更新。
```

## 四、仿真结果要怎么写

会议中确认当前主要看四个结果：

1. 中心磁场 `Bcenter`
2. 屏蔽因子 `SF`
3. 总积分值 `IntH2_total`
4. 外层贡献 `IntH2_outer`

论文中 hybrid 结果要围绕这四个指标写。

### 当前横向 hybrid 结果

已有结果：

```text
四层铁氧体：
SFx = 3.629
IntH2_total = 4.160e-06

四层铁氧体 + 非晶外层：
SFx = 8.548
IntH2_total = 6.283e-07

四层铁氧体 + 纳米晶外层：
SFx = 25.146
IntH2_total = 5.333e-08
```

会议结论：

- 原四层铁氧体 SF 只有 3 点多，偏低。
- 加非晶能提高到 8 点多。
- 加纳米晶能提高到 25 点多，提升显著。
- `IntH2_total` 还下降，说明在当前仿真假设下不仅 SF 提升，磁噪声相关积分也没有变差。
- 外层也应计入 IntH2，不应只算四层铁氧体。

论文中建议写：

```text
Compared with the ferrite-only base, the amorphous outer layer increases SFx from 3.63 to 8.55, while the nanocrystalline outer layer further increases SFx to 25.15. Meanwhile, IntH2_total decreases from 4.16e-6 to 6.28e-7 and 5.33e-8 for the amorphous and nanocrystalline hybrid cases, respectively. The IntH2 integration includes both the ferrite layers and the added outer high-permeability layer.
```

必须注意：

```text
不能写“已经证明噪声一定下降”；
应该写“磁噪声相关积分下降，在当前材料损耗假设下是有利趋势”。
```

因为非晶/纳米晶真实噪声还要看 `mu''`。

## 五、实物样机怎么设计

会议中对 P0/P1/P2 有新要求。

### P0 不能是无屏蔽

师兄明确说：

```text
P0 不建议是无屏蔽参考，因为 SERF 剩磁会很大，可能测不出来。
```

因此 P0 应改成有屏蔽的参考结构。

当前项目已按这个方向改为：

```text
P0: 单层非晶圆柱壳 + 单边非晶封盖
```

这是合理的。

### 建议实物对比组

会议中师兄建议：

```text
可以做不同层数铁氧体，比如两层、四层；
再做四层加纳米晶；
或者做纯非晶一组。
```

结合当前项目，建议实物实验分两级：

#### 必做组

```text
P0: 单层非晶壳 + 单边非晶盖
P1: 四层铁氧体
P2: 四层铁氧体 + 纳米晶外层
```

#### 可选补充组

```text
P1-2L: 两层铁氧体
P1-4L: 四层铁氧体
P0-AM: 纯非晶结构
```

如果时间紧，优先：

```text
P0 / P1 / P2
```

论文中可以写：

```text
The prototype validation is designed around three practical configurations: a single amorphous shell-cap reference, a four-layer ferrite prototype, and a four-layer ferrite shield with a selected nanocrystalline outer layer.
```

## 六、为什么选四层铁氧体

会议中师兄强调：

- 层数不能无限多。
- 更多层可能屏蔽更好，但可弯曲性和装配会变差。
- 四层拼起来可能已经接近弯曲/装配极限。
- 可以通过实物弯曲性或机械可行性说明“四层”的选择。

论文不能写：

```text
四层是全局最优。
```

应该写：

```text
四层是在屏蔽性能、总厚度、径向空间、柔性弯曲和装配可行性之间的折中候选。
```

建议写法：

```text
Although increasing the number of ferrite sheets may further improve shielding, the multilayer stack becomes increasingly difficult to bend and assemble. The four-layer ferrite base is therefore selected as a manufacturable validation candidate under the present total-thickness and flexibility constraints.
```

后续最好补一个实物机械说明：

```text
1 层/2 层仍可弯曲；
4 层明显变硬或接近装配极限；
因此四层作为样机基体。
```

## 七、封盖实验怎么写

会议中提到：

- 之前盖子严丝合缝贴合时网格难收敛。
- 可以加间隙，例如通过塑料外壳支撑，实际结构中盖和筒之间并非完全零间隙。
- 这可以作为仿真合理化依据。

论文中建议写：

```text
In the axial cap simulation, a small axial gap is introduced between the cylindrical shield and the cap to represent the mechanical support and to avoid an unrealistically sharp zero-gap contact in the FEM mesh.
```

中文逻辑：

```text
不是为了让仿真容易而随便加缝；
实物中有塑料支撑和装配间隙；
仿真中加入小间隙更接近工程结构，也改善网格收敛。
```

## 八、应用部分怎么写

会议后半段提到：

- 论文应用可以向 OPM / MEG / 可穿戴磁屏蔽靠近。
- 可穿戴或可运动状态下的脑磁测量是潜在应用。
- 当前不需要真的做脑磁实验，但要把应用意义说清楚。

建议 Discussion 或 Introduction 末尾写：

```text
The long-term application target is a lightweight and potentially wearable magnetic shielding environment for OPM- or SERF-based biomagnetic measurements. Compared with rigid MSR systems, flexible ferrite and nanocrystalline ribbon structures may provide a more compact and lower-cost route toward motion-tolerant magnetometer measurements.
```

注意不要写成已经实现可穿戴 MEG，只能写：

```text
potential route
application target
future validation
```

## 十、最重要的论文口径

可以写：

```text
纳米晶外层在当前仿真中显著提高 SFx，并降低 IntH2_total。
当前磁导率取值代表低场初始磁导率假设。
```
