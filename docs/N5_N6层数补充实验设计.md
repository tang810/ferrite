# N=5 / N=6 层数补充仿真实验设计

## 1. 为什么要做这个补充实验

目前论文主线里，四层铁氧体结构 `C2_N4_t015_g008_x` 已经作为样机候选结构。它的参数是：

| 项目 | 数值 |
| --- | ---: |
| 内半径 Rin | 100 mm |
| 长度 L | 200 mm |
| 层数 N | 4 |
| 单层铁氧体厚度 | 0.15 mm |
| 层间间隙 | 0.08 mm |
| 铁氧体总厚度 | 0.60 mm |
| 径向总占用 Tspace | 0.84 mm |
| SFx | 3.629 |
| IntH2_total | 4.160e-06 |

但是论文里不能只写“四层最好”，因为目前还没有把 5 层、6 层放进同一约束下比较。这个补充实验的作用，就是把四层选择逻辑补得更扎实：

> 在总铁氧体厚度固定为 0.60 mm 的前提下，继续增加层数到 N=5、N=6，观察 SFx 和 IntH2_total 是否还有明显收益，以及这种收益是否值得增加径向占用和装配难度。

所以这个实验不是为了推翻四层方案，而是为了回答：

1. 四层之后，继续分层是否还明显提高 SFx？
2. IntH2_total 是否继续下降，还是收益变小？
3. 如果 N=5/N=6 只带来很小提升，但径向占用和制造难度增加，那么四层作为样机候选就更合理。

## 3. 实验参数怎么设计

这组实验固定下面这些条件：

| 条件 | 数值 |
| --- | ---: |
| 内半径 Rin | 100 mm |
| 长度 L | 200 mm |
| 总铁氧体厚度 | 0.60 mm |
| 层间间隙 | 0.08 mm |
| 外场方向 | x 向 |
| 铁氧体相对磁导率 | 1000 |
| 铁氧体电导率 | 0.01 S/m |
| 对比基准 | C2_N4_t015_g008_x |

新增两个 case：

| case_id | 层数 | 单层厚度 | 层间间隙 | 铁氧体总厚度 | 径向总占用 | 最外半径 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| C2_N5_t012_g008_x | 5 | 0.12 mm | 0.08 mm | 0.60 mm | 0.92 mm | 100.92 mm |
| C2_N6_t010_g008_x | 6 | 0.10 mm | 0.08 mm | 0.60 mm | 1.00 mm | 101.00 mm |

这里的关键点是：总铁氧体厚度一直是 0.60 mm。也就是说，N=5/N=6 不是靠“加更多铁氧体材料”来赢，而是单纯比较分层结构本身的影响。

## 4. 脚本具体做了什么

脚本会复制已经验证过的四层横向基准项目：

`round2_working/manufacturable_thin/C2_N4_t015_g008_shield.aedt`

然后对每个 case 做下面几步：

1. 删除原来的四层铁氧体实体。
2. 按 N=5 或 N=6 重新生成连续圆筒铁氧体壳。
3. 保留原来的空气域、外场线圈、中心观测点和 Setup1 设置。
4. 重新划分薄层网格。
5. 运行 `Analyze Setup1`。
6. 导出中心磁场 `Bcenter_Bx_T`、`Bcenter_By_T`、`Bcenter_Bz_T`。
7. 计算 `SFx`、`ResidualRatiox`。
8. 对所有铁氧体层逐层积分，得到 `IntH2_total`。
9. 和四层基准比较，输出 `SFx_gain_vs_N4` 和 `IntH2_ratio_vs_N4`。

## 5. 希望得到什么结果

最理想的情况不是单纯看 SFx 越大越好，而是看 SFx 和 IntH2_total 的权衡。

### 情况 A：N=5/N=6 明显提升 SFx，IntH2_total 也下降

这说明继续增加层数确实有收益。论文中要把四层表述得更谨慎：

> 四层是当前优先样机结构，但更高层数在仿真中可能进一步改善屏蔽性能，后续可作为结构优化方向。

如果 N=6 明显优于 N=4，并且加工上也能做，那样机方案可能要重新讨论。

### 情况 B：N=5/N=6 只小幅提升 SFx，IntH2_total 变化不大

这是最有利于当前论文主线的结果。

可以写：

> 在总铁氧体厚度固定的情况下，四层以后继续增加层数的边际收益减小。考虑径向占用和装配可行性，四层结构被选为后续样机验证候选。

这能很好支撑“四层不是随便选的”。

### 情况 C：N=5/N=6 的 SFx 提高，但 IntH2_total 也明显升高

这说明层数增加带来了屏蔽性能提升，但可能引入更高的磁噪声相关积分指标。论文里就要强调：

> 本工作不是只追求最大 SF，而是同时考虑 SF 和 IntH2_total。

这种情况下，四层作为折中方案也仍然有道理。

### 情况 D：N=5/N=6 收敛很慢或网格困难

这本身也是有意义的工程信息。因为 N=6 的单层厚度只有 0.10 mm，薄层越多，网格越难，计算量和加工难度都会增加。

论文里可以写：

> 更高层数结构受到薄层网格、径向装配间隙和制造可行性的限制，因此本阶段优先选择四层结构进行样机验证。

## 6. 跑完以后怎么看结果

运行后先看日志：

```powershell

```

```powershell
Import-Csv .\data\raw\high_layer_count_exports.csv |
  Select-Object case_id,N_layers,t_ferrite_mm,T_space_mm,SFx,SFx_gain_vs_N4,IntH2_total,IntH2_ratio_vs_N4,status |
  Format-Table -AutoSize
```

如果 `status` 是 `exported`，并且 `SFx`、`IntH2_total` 都有数值，说明这组仿真数据可以进入后处理。
