# 实验补全步骤

把 `data/experiment_matrix_main.csv` 里的 planned/missing 占位实验拆成可执行步骤。不要补假数据，做完一步再更新对应 case 的 status。

总体流程：打开实验矩阵挑一个 status 为 missing/planned/built 的 case → 按 AEDT手动操作清单 建模求解导出 → B0 reference 放进 data/raw/ → 中心场追加到 center_field_raw.csv → IntH2 追加到 intH2_layerwise_raw.csv → 跑后处理验证脚本 → 通过后才标 used_in_paper。

## 第一阶段：B0 Reference

B0_reference_x（横向 x 外场无屏蔽参考）已完成并验证通过。

B0_reference_z（轴向 z 外场无屏蔽参考）：复制 B0_reference_x，外场改 z 向，保持空气域、边界、中心点一致，导出 B0_Bx/By/Bz/Mag_T，存为 data/raw/B0_reference_z.csv，跑 validate_B0_reference.py 确认 B0_Bz_T 主导。

## 第二阶段：Priority 1 连续壳 x 向主矩阵

这 7 个 case 是论文主筛选矩阵，已完成：

C1_N1_t008_x, C1_N1_t020_x, C1_N1_t040_x, C1_N1_t060_x, C2_N2_t020_g010_x, C2_N3_t020_g010_x, C2_N4_t015_g008_x

每个 case 的步骤：打开 AEDT 工程 → 检查几何参数 (Rin=100, H=200, N, t, g) → 每层铁氧体独立实体 → x 向外场 → 求解 → 导出中心场 → 导出 IntH2_total + 各层 IntH2_Li → 跑后处理和验证。验证失败就保持 failed 或 missing。

## 第三阶段：Priority 2 补充实验

### z 向轴向扩展

C1_N1_t060_z, C2_N3_t020_g010_z, C2_N4_t015_g008_z。等 priority-1 x 向有可比较结果后再做。必须用 B0_reference_z，SFz 用 Bz 分量算，别用 x 向结果推 z 向。

S1 系列 (N=1, t=0.60, seg12 aligned/staggered) 和 S2 系列 (N=3/4, seg12 aligned/staggered)。连续壳筛选完确定需要分段修正再做。每层切 12 个周向条，周向缝 1.6mm。aligned 各层缝对齐，staggered 相邻层错开 pi/12。导出中心场和 IntH2_total，跟连续壳比。

MU_C2_N3_t020_g010_x (mu=500/2000/5000)。只改 mu_r，其他几何边界网格不变。结果只说明结构排序对材料磁导率的敏感性，不替代实测材料参数。

### 网格收敛性

MESH_C1_N1_t008_x 和 MESH_C2_N4_t015_g008_x。至少比 coarse/medium/fine 三组，监控 Bcenter_Bx_T, SFx, IntH2_total。没做完收敛性检查前论文结论保持 pending。
